# Personal Expense Tracker Web Application

## Project Description
The Personal Expense Tracker is a responsive frontend web application designed to help users log, monitor, and evaluate their cash flows, incomes, and expenses. It features persistent storage via browser `localStorage`, live metric updates, and record searching.

## Target Users and Objectives
* **Target Users:** Students, independent budget planners, and individuals tracking personal expenditures.
* **Objectives:**
  1. Provide clear balance summaries and tracking of incoming/outgoing funds.
  2. Implement client-side form validation for data integrity.
  3. Support persistent client storage using `localStorage`.

## Features & Technologies Used
* **Technologies:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5.3
* **Key JavaScript Features:**
  1. Dynamic calculations of balance, income, and expense totals.
  2. Client-side data persistence (`localStorage`).
  3. Real-time transaction filtering and search logic.

## Instructions for Opening and Using the Application
1. Download or clone the project repository.
2. Open `index.html` in any modern web browser.
3. Use the input form on the dashboard to add incomes or expenses, and navigate across history and analytics pages.
